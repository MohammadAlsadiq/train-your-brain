# Train Your Brain

An interactive website created for my **Learning How to Learn** final project on Coursera. It connects course concepts with practical examples from computer science and everyday learning.

## Features

- Recall activity with confidence feedback
- Spaced-review planner with calendar export
- Pomodoro focus and break timer
- Learning strategy activities
- Flashcards with custom questions and difficult-card practice
- Reflection notebook and progress saved in your browser

## Built With

HTML, CSS, and vanilla JavaScript. The design follows my personal website’s dark theme with cyan and purple accents.

## Run Locally

Download or clone this repository, then open `index.html` in your browser. No installation or build step is required.

## Project Files

- `index.html` — page content and structure
- `styles.css` — styling and responsive layout
- `script.js` — interactive features and browser storage

## Deploy

Upload the files to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Learning Topics

Recall, illusions of competence, spaced practice, procrastination, focused and diffuse thinking, chunking, and interleaving. Course and research references are included on the website.

## Notes

Saved data stays in the current browser and does not sync between devices. Use **Reset saved lab data** to clear it. Google Fonts requires an internet connection; fallback fonts are available.
